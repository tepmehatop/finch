# Finch

Десктопное приложение для работы с терминалами и coding-агентами: GigaCode,
Claude Code, Codex и другими. Работает на macOS (Apple Silicon и Intel) и Linux.

## Что умеет

- **Пространства, вкладки и панели.** Пространство — работа в одной папке или
  репозитории. В нём вкладки, вкладку можно делить на панели: терминалы, чат агента,
  файлы, изменения.
- **Агенты живут вне окна.** Терминалы и агенты запущены в фоновом процессе
  `finch-core`. Окно можно закрыть, обновить или даже уронить: агенты продолжат работу,
  а после открытия всё будет на своих местах. После перезагрузки «удержанные»
  панели открываются в своих папках.
- **Сайдбар агентов.** Статусы «Работает», «Ждёт вас», «Готово», «Простаивает»,
  в том числе для помощников, которых агент запустил сам.
- **Чат агента.** Переписка с агентом в виде чата: ответы в Markdown, свёрнутые
  размышления, карточки вызовов инструментов с результатами. Поле ввода отправляет
  сообщение в терминал агента. Подробнее — ниже.
- **Git.** Панель «Изменения» с диффами и коммитом, worktree для параллельных задач.
- **Настройка под себя.** Палитра команд (⌘⇧P / Ctrl+Shift+P), раскладки окна,
  темы, свои клавиши в `keys.json`. Интерфейс собирают моды на JavaScript —
  их можно менять и писать свои (см. [docs/mods.md](docs/mods.md)).
- **Русский и английский интерфейс.** Переключатель на экране приветствия и в
  «Настройки › Вид».

## Редакции

| | Полная | Закрытый контур |
|---|---|---|
| Агенты | GigaCode, Claude Code, Codex, Gemini, Qwen и другие | только GigaCode |
| Другие машины по SSH | есть | нет |
| Платформы | macOS Apple Silicon, macOS Intel | macOS Apple Silicon, macOS Intel, Linux x86_64 |

Ни одна редакция не обновляется сама, не отправляет статистику и ничего не скачивает.
Ядро `finch-core` поставляется внутри приложения.

## Установка

Готовые сборки — в разделе Releases репозитория.

**macOS.** Распакуйте архив в «Программы» и снимите карантин (сборка без подписи Apple):

```sh
tar -xzf finch-closed-macos-x86_64.tar.gz -C ~/Applications
xattr -dr com.apple.quarantine ~/Applications/"Finch Closed.app"
```

**Linux.** Распакуйте архив и запустите `finch` из папки. Нужны графическая сессия
и драйвер Vulkan.

```sh
tar -xzf finch-closed-linux-x86_64.tar.gz -C ~/.local/share
~/.local/share/finch-closed/finch
```

**Обновление.** Скачайте новую версию и распакуйте поверх старой. Терминалы и агенты
при этом продолжают работать.

## Чат агента

Чат открывается рядом с терминалом агента тремя способами:

- меню **«+»** → выберите агента: при включённой галочке «Открывать чат вместе с агентом»
  чат откроется сам;
- кнопка **«Чат»** в заголовке панели агента;
- **⌘⇧J** (на Linux — Ctrl+Shift+J) в терминале агента.

Чат читает журнал сессии агента (`~/.gigacode/…`, `~/.claude/projects/…`). В памяти
держится только конец разговора, более ранние сообщения подгружаются кнопкой
«Показать ранее», поэтому сессии на десятки часов не нагружают компьютер.

## Командная строка

- `finch ls`, `finch status`, `finch commands` — что открыто в окне и какие есть команды.
- `finch do <команда>` — выполнить команду окна, например `finch do agent.chat`.
- `finch --skill` — руководство для агентов, которые управляют окном.
- `hc` — командная строка ядра: `hc ls`, `hc read t3`, `hc send t3 "текст"`,
  `hc attach t3`. Справка: `hc --help`.

## Настройки и файлы

Всё лежит в `~/.config/finch/`: `settings.json` (язык, шрифты, темы), `keys.json`
(клавиши), `layouts/` (раскладки), `mods/` (моды), `programs.json` (как показывать
программы и каких агентов запускать). Руководство по этим файлам —
`~/.config/finch/AGENTS.md`.

## Сборка из исходников

Нужны Rust 1.95.0, Zig 0.16.0 и сабмодули:

```sh
git submodule update --init
scripts/finch-package full                            # эта машина, полная редакция
scripts/finch-package closed x86_64-apple-darwin      # macOS Intel, закрытая редакция
scripts/finch-package closed x86_64-unknown-linux-gnu # на Linux-машине
```

Готовый архив появится в `dist/`. На Linux нужны пакеты разработки: pkg-config, clang,
libxcb, libxkbcommon, libwayland, libvulkan, libfontconfig, libfreetype.

Тесты: `cargo test --locked -p finch -p finch-shell` и `bun test scripts/*.test.ts`.
