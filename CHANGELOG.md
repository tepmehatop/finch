# Изменения

## [0.1.0] - 2026-11-27

### New

- **Чат агента.** Переписка с GigaCode, Claude Code или Qwen Code в виде чата рядом с терминалом: Markdown, размышления, вызовы инструментов. Открывается из меню «+», кнопкой «Чат» в заголовке панели или ⌘⇧J.
- **Русский интерфейс.** Переключатель языка на экране приветствия и в «Настройки › Вид».
- **Редакция для закрытого контура.** Только GigaCode, без других машин и без сетевых функций.
- **macOS Intel.** Сборки для Intel и Apple Silicon; ядро поставляется внутри приложения.
