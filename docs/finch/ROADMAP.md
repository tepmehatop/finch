# Finch: план

## Редакции и платформы

| Сборка | Агенты | Обновления | Телеметрия |
|---|---|---|---|
| macOS Apple Silicon — **full** | все, что знает Finch, + GigaCode | наш канал `<base>/full` | только на наш сервер, если задан |
| macOS Intel — **full** | то же | то же | то же |
| macOS Apple Silicon — **closed** | только GigaCode | канал `<base>/closed` или внутренний сервер в контуре | выключена всегда |
| macOS Intel — **closed** | только GigaCode | то же | выключена всегда |
| Linux x86_64 — **closed** | только GigaCode | то же | выключена всегда |

Редакция выбирается при сборке (`FINCH_EDITION=full|closed`, см. `src/edition.rs`).
Ядро `hc` лежит внутри пакета, поэтому при первом запуске ничего не скачивается.

## Открытые вопросы

1. **Подпись macOS.** Без Developer ID ($99/год) сборки подписаны ad hoc:
   после распаковки нужен `xattr -dr com.apple.quarantine "Finch.app"`.
2. **Минуты CI.** macOS-раннеры в приватных репо тарифицируются ×10. Альтернатива —
   собирать macOS локально тем же `scripts/finch-package` (Intel кросс-компилируется на Apple Silicon).
